# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## วิธีติดตั้ง
uv sync --locked

## แหล่งข้อมูล

- ข้อมูลสถานีและค่าคุณภาพอากาศล่าสุดมาจาก [Air4Thai โดยกรมควบคุมมลพิษ](https://air4thai.pcd.go.th/) ผ่าน [JSON endpoint](https://air4thai.pcd.go.th/services/getNewAQI_JSON.php) (ตรวจสอบเมื่อ 2026-11-28) โดยเวลา observation อยู่ใน `AQILast.date` และ `AQILast.time`; เวลาในชื่อไฟล์เป็นเวลาที่โปรเจกต์ดึงข้อมูล
- ตรวจ `http://air4thai.pcd.go.th/robots.txt` เมื่อ 2026-11-28 แล้วพบว่า redirect ไป HTTPS และตอบ `404 Not Found` จึงไม่มี robots directives ให้อ่านจาก path นี้ ผลนี้ไม่ใช่การอนุญาตอย่างชัดแจ้งให้ใช้หรือเผยแพร่ข้อมูล และ `robots.txt` ไม่ใช่ใบอนุญาตด้านข้อมูล
- ใช้ข้อมูลเพื่อการศึกษาในโครงการนี้ และอ้างอิง Air4Thai/กรมควบคุมมลพิษพร้อมลิงก์ endpoint เมื่อนำเสนอผล ควรส่ง request อย่างเหมาะสม ไม่เรียกถี่จนรบกวนบริการ และตรวจสอบเงื่อนไขปัจจุบันกับเจ้าของข้อมูลก่อนเผยแพร่หรือแจกจ่ายข้อมูลต่อ
- endpoint สาธารณะนี้ไม่ต้องใช้ API key; `.env.example` จึงไม่มี credential สำหรับแหล่งข้อมูลปัจจุบัน
